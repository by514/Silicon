# 音乐播放器（Music Player）

玩家随身 UI 的音乐播放器（非方块，不影响旧存档方块 ID）。支持内置原版音乐、网络 URL、本地文件三种曲目，
声源随播放者移动，**其他玩家按自己到播放者的距离远近听到**（多人 3D 声场）。

## 入口（三种都要）

1. **设置菜单**：Silicon 设置分类 → 「音乐播放器」按钮
2. **快捷键**：默认 `F9`，按下直接弹出播放器弹窗
3. **常驻悬浮条**：屏幕右下角音符按钮 `♪`，点击展开为迷你控制条（播放/暂停、曲名、下一曲、收起）；**可拖动到任意位置**（收起态整条可拖、展开态前端把手拖动），位置跨会话记忆

## 播放器功能（完整播放器）

- 播放 / 暂停 / 停止
- 上一曲 / 下一曲
- 音量（0~100%）
- 音高（0.5x~2.0x）
- 循环模式：关闭 / 列表循环 / 单曲循环
- 曲目列表管理：点击即播、移除曲目
- 添加曲目：游戏内置 / 网络 URL / 本地文件路径

## 曲目类型

| 类型 | 来源 | 共享方式 |
|------|------|---------|
| INTERNAL | 游戏内置原版音乐（Musics.*：game1~9、boss1/2、fine、editor、menu、land、launch） | 所有人本地都有，广播元数据即可播放 |
| URL | 网络音频地址（.ogg/.mp3/.wav） | 播放者广播 URL，其他客户端下载到本地缓存后播放 |
| LOCAL | 播放者本地磁盘路径 | 播放者读取文件字节，二进制分块广播，其他客户端重组写缓存后播放 |

## 多人 3D 声场

- **播放者（owner）**：本人正常播放，声源以其世界坐标为原点。
- **其他玩家**：以「自己到 owner 的距离」做 3D 衰减，越近越清晰，超过衰减半径基本听不见。
- **可叠加**：多个玩家同时播放时，各声源独立叠加，互不冲突。
- **链路**：播放者 → 服务端 → 广播所有客户端 → 各端本地 3D 定位播放。
- 「启用」开关：关闭时本机不能播放，同时不接收/听不到别人的播放（双生效）。

## 本地缓存优先复用

- URL 下载、二进制广播收到的文件均缓存到 `cache/music/<hash>.<ext>`（保留原始扩展名，供 Soloud 按扩展名解码）。
- 再次播放（含他人播放同源曲目）时命中缓存直接复用，不再走网络。
- 缓存文件以内容 hash 命名，天然去重；跨重启也能通过 `<hash>.*` 扫描命中。
- 首帧共享：URL/网络播放时元数据携带 `ext`、`x`/`y`，让对端即时定位声源并正确解码。

## 网络注册时机

- `netClient`/`netServer` 在 mod init 时可能尚未创建，因此包处理器延迟到对应端加载完成事件注册：
  - 客户端：`ClientLoadEvent` 注册 `MusicNetwork` 的接收/发送回调
  - 服务端：`ServerLoadEvent` 注册转发回调（客户端上报 → 广播所有客户端）
  - 均带防重入标志，只注册一次
- 玩家离开（`PlayerLeave`）时清理其声源、坐标与接收缓冲，避免脱离后声源残留。
